# Proyecto: Máquina de Turing (Fibonacci)

Este repositorio contiene una Máquina de Turing determinista de 1 cinta que calcula la sucesión de Fibonacci y un pequeño análisis empírico del tiempo/pasos de ejecución según el tamaño de entrada.

## Archivos principales
- `main.py`: ejecución principal de la simulación.
- `tm_loader.py`: carga/lectura de la máquina desde archivo.
- `turing_machine.py`: lógica del simulador (configuraciones, pasos, estado, cinta).
- `unary_utils.py`: utilidades para la convención unaria.
- `fibonacci_tm.txt`: definición/componentes de la Máquina de Turing de Fibonacci.
- `convenciones.md`: convención de entrada/salida e interpretación del resultado.

## Diagrama
- `diagrama_mt.png`: diagrama de la Máquina de Turing.
- `create_diagram.py`: script para generar el diagrama.

## Análisis empírico
- `empirical_analysis.py`: genera mediciones y gráficas.
- `datos_empiricos.txt`: entradas/datos usados para el análisis.
- `grafica_tiempo.png`, `grafica_pasos.png`, `grafica_combinad*.png`: resultados del análisis.
